# weights/

이 폴더는 비어있는 게 정상입니다. **가중치 파일(`.pt`)은 이 저장소에 포함하지 않습니다.**

두 모델(`cbas_best.pt`, `yolo_best.pt`) 모두 양산부산대학교병원 환자 데이터로 학습된 결과물이라,
원본 데이터를 직접 공개하지 않더라도 "그 데이터를 학습한 파생물"에 해당합니다. 이걸 공개 저장소에
올려도 되는지는 데이터 사용 동의서(DUA)·IRB 승인 조건에 따라 달라질 수 있어서, **확인 전까지는
비공개로 관리**합니다.

| 파일명 | 설명 |
|---|---|
| `cbas_best.pt` | CBAS-UNet2D segmentation 모델 (fold0 best) |
| `yolo_best.pt` | YOLOv11x lesion detection 모델 |

## 재현하려면

- **코드 자체(`train.py`, `inference/predict_fusion.py` 등)는 공개**되어 있으므로, 직접 데이터를
  준비해서 학습하면 동일한 파이프라인으로 가중치를 재현할 수 있습니다.
- 팀 내부적으로 가중치가 필요하면 (GitHub가 아닌) NAS·메신저 등 별도 채널로 직접 전달받으세요.
- 외부 공개(GitHub 등)가 필요해지면, 지도교수님께 DUA/IRB상 가중치 배포 가능 여부를 먼저 확인한
  뒤 이 폴더에 다시 추가하면 됩니다 (`.gitattributes`에 Git LFS 추적 설정은 이미 준비되어 있음).
